# 四通道 IV 测量系统（面包板版）

> 用一个 Arduino Nano + 14 只光耦 + 3 块面包板，配合两台 Keithley DMM6500，
> 轮流测量 **4 个相互独立的光电器件**的开路电压（Voc）和短路电流（Isc），
> 并能连续记录 **7 天以上**。
>
> **零焊接、零打板**，全部用面包板和杜邦线搭出来。
> 本指南假设你**从没用过 Arduino、也没用过面包板**。

---

## 这个系统在做什么（30 秒版）

普通万用表一次只能测一个器件。要测 4 个器件，常见做法是买 4 台表（贵）或者用机械继电器切换（漏电大、寿命短）。

本系统用**光耦继电器（PhotoMOS）**做切换：

```
                    ┌──────────────────────────────┐
   Arduino Nano ────┤ 光耦阵列（14 只）            ├──── 被测器件 1~4
   （控制侧）        │  · 12 只：通道选通 + 短接     │       ↕
                    │  ·  2 只：切换电压表/电流表   │    万用表 ×2
                    └──────────────────────────────┘      （测量侧）
                        ↑ 光隔离，两侧地不共用
```

**关键规则**：器件只有在"被测的那一瞬间"才接到万用表，其余时间被**短路（测 Isc 时）或开路（测 Voc 时）**——这样既不会互相干扰，也符合器件长期工作的条件。

**为什么用光耦而不是机械继电器**：机械触点有寿命限制（几万次就坏）、触点漏电和热电势不可控；光耦无触点、漏电只有 µA 级、可以长期连续切换。

## 每一步的"验收标准"

不要凭感觉判断做完了没有，用这些客观标准：

- **第 2 步做完**：Arduino IDE 里点上传，串口监视器（115200）能看到 `READY v1.1`
- **第 3 步做完**：串口监视器敲 `i1`，能听到/看到光耦-1 亮（用手机相机拍光耦，能看到红外 LED 的微弱紫光），敲 `s` 全部熄灭
- **第 4 步做完**：运行 `check_devices.py`，三行都是 `OK`
- **第 5 步做完**：界面上三张图有曲线在走，`D:\IV_data\` 下出现当天的 CSV 文件

| 控制协议 | 串口 115200，简单文本命令 |

## 一句话说明"为什么需要两台万用表"

电压表和电流表**不能同时接在同一个器件上**——电流表的取样电阻（约 1 Ω）会把电压表短路掉，读到的电压永远是 0。

所以系统里用 2 只光耦做"模式切换"：这一瞬间整个 4 路母线要么全接电压表、要么全接电流表。
如果你只有一台 DMM6500，也可以跑（软件会来回切功能和量程），只是每轮慢一些、且量程切换会引入额外误差。
