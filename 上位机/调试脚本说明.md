# 调试脚本说明（新手可以跳过）

> 这个目录（`上位机\`）里除了运行软件必需的几个文件，还有一批 **`probe_*` / `test_*` 脚本**。
>
> **如果你只是想正常使用系统，这些脚本你一个都不需要运行。**
> 它们是开发和排查问题时用的，需要接上真实硬件、并且知道自己在做什么。

---

## 正常运行只需要这些

| 文件 | 作用 |
|---|---|
| `启动上位机.bat` | ★ 双击这个就能开界面 |
| `config.yaml` | ★ 配置（COM 口、万用表地址、采样间隔） |
| `check_devices.py` | ★ 设备自检（三行都 OK 才说明硬件就绪） |
| `main_gui.py` | 图形界面主程序 |
| `main.py` | 命令行版（界面打不开时可以试它） |
| `inspect_db.py` | 查看已存的数据 |
| `ivcore\` `ui\` | 内部模块，不用管 |
| `数据存储说明.md` | 数据格式详解 |

## 这些 `probe_*` / `test_*` 是干什么的

### 电源协议探测（运行时会给电源发命令，会改变电源状态）

| 脚本 | 用途 | 会改电源状态吗 |
|---|---|---|
| `probe_power_protocol.py` | 系统性探测电源支持哪些 MODBUS 功能码（读几个寄存器、写几个、线圈、0x06） | 会（测完自动恢复） |
| `probe_power_endian.py` | 决定性实验：控制字到底该"高字节先"还是"小端" | 会（会开关输出） |

**这两个是当初摸清电源协议的关键** —— 靠它们才确认了：

- 读只支持 `0x03 count=8`，写只支持 `0x10 count=3`
- 线圈功能完全不支持
- 控制字必须高字节先（发 `01 00` 才能开输出，发 `00 01` 不行）

### 回归测试（用于确认改动没弄坏功能）

| 脚本 | 测什么 | 前提 |
|---|---|---|
| `test_power_isolate.py` | 9 项：设电压/设限流/开关输出是否互不干扰 | 要接电源 |
| `test_view_span.py` | 视图跨度（10分钟/1小时/自定义）是否精确生效 | 无头（offscreen）即可 |
| `test_y_zoom.py` | Y 轴缩放是否被保留、缩放温度图是否影响电信号图 | 无头 |
| `test_zoom_keep.py` | 滚轮缩放后范围是否被自动重置 | 无头 |
| `test_zoom_temp.py` | 缩放横坐标后温度曲线是否消失 | 无头 |

> 标"无头"的可以直接跑，不需要真实硬件（会自动用模拟模式）：
> ```powershell
> python test_view_span.py
> ```

## 什么时候需要跑它们

| 情况 | 跑什么 |
|---|---|
| 怀疑电源控制有问题 | `python probe_power_protocol.py COM13` 先看设备到底支持什么 |
| 改了电源相关代码 | `python test_power_isolate.py COM13` 确认没弄坏 |
| 图表的缩放行为不对 | `python test_y_zoom.py` / `test_zoom_keep.py` |
| 改完界面想快速验证 | `test_view_span.py` + `test_zoom_temp.py` |

---

## 注意

1. **`probe_*` 脚本会真的给电源发命令**，运行时请确认电源接着负载、且你不在做别的实验
2. 这些脚本里的 COM 口是**命令行参数**，默认 `COM13`，换口就 `python xxx.py COM5`
3. 脚本输出是中文，如果 PowerShell 显示乱码，先执行 `chcp 65001`
